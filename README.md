## Source

Everything I ship is open source. I came up on the market side, trading and investing on CT since 2021. These days most of my time goes into writing code and researching AI, and whatever I build goes public.

### What's out

The ten newest. Every repo, each with its own page, is on **[drk.vc/source →](https://drk.vc/source)**

| Repo | What it is |
| --- | --- |
| [photo](https://github.com/drkxbt/photo) | A photo editor for websites. Crop, turn, flip and straighten, adjust the light and colour, draw, write and hide parts of the picture, and undo any of it. Plain TypeScript, no dependencies. |
| [palette](https://github.com/drkxbt/palette) | A command palette for websites. Ctrl or Cmd+K opens a search over pages, actions and things to copy; it finds by the first letters of words and ignores accents. Plain TypeScript, no dependencies. |
| [sheet](https://github.com/drkxbt/sheet) | A bottom sheet for websites. It stops at its content's height or where you set, follows the finger, closes with a flick and stays above the keyboard. Plain TypeScript, no dependencies. |
| [lightbox](https://github.com/drkxbt/lightbox) | An image viewer for websites. Pictures grow out of their thumbnails and fly back when closed; swipe between them, drag down to close, pinch to zoom. Plain TypeScript, no dependencies. |
| [motion](https://github.com/drkxbt/motion) | Small animated details for websites: buttons, icons, components and loading states. Plain CSS and TypeScript, no dependencies. |
| [charts](https://github.com/drkxbt/charts) | Four canvas charts for markets: candles, a price line, order book depth and a market heatmap. Plain TypeScript, no dependencies. |

### Where things live

- **GitHub** has the code, the issues and the full history of every repo.
- **[drk.vc/source](https://drk.vc/source)** has a page for each repo: what it does, the features it ships with, screenshots, how it works, the stack, and how to run it locally.

### Using the code

Clone it, fork it, take it apart. Each repo states its license in its own `LICENSE` file, so check that before you reuse anything in your own project.

### Contributing

Issues and PRs are welcome on every repo. If something breaks, open an issue and say what you did and what you expected to happen. If you can fix it, send a PR with a short note on what changed and why.

### Staying in the loop

New repos and updates get posted on [X](https://x.com/drkxbt) first. For anything else, my DMs on [Telegram](https://t.me/drk9999) are open.
